# Perfil SDP Dataset (ilustrativo)

Um pacote pode conter somente dados. Por exemplo: `kind:"dataset"`, `purpose:"Distribuir amostras de dados"`, `profiles:[]` e `payload/observacoes.csv`. **Não exige `entry`, código JavaScript, permissões, host COVIL ou API de inicialização.**

Um perfil de dados futuro poderá descrever schema de tabelas, unidade de medidas, origem declarada, licença, versões e privacidade. Essas afirmações devem permanecer **autodeclaradas**, verificadas pelo portador e nunca validadas automaticamente como fatos pelo hash.
